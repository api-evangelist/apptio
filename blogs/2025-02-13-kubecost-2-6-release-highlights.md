Kubecost 2.6 is here, bringing a major upgrade to Role-Based Access Control (RBAC)! This release gives Kubernetes administrators greater flexibility and control, enabling them to customize user access with more precision across the Kubecost UI. Granular RBAC: More Control, More Security Kubecost 2.6 gives administrators greater control over user access, enhancing both security and usability.
